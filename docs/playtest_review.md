# v1 파일럿 1차 자체 리뷰 (2026-10-24, 브라우저 자동 플레이 기준)

실기기 터치 테스트 전 단계의 리뷰입니다. 실제 손맛·프레임은 T17(플레이 테스트 계획)에서 검증해야 합니다.

## 1. 스토리라인

**강점**
- 훅이 좋음: 13장 전체 뽑기 → 자랑 → 글리치 → 사고 → 응원봉 목소리. 1분 안에 "왜 내가 이 세계에 들어왔는지"가 체감됨.
- 주제("빛은 혼자 내는 게 아니라 함께 모으는 것")가 W3·W4·Final 대사와 정확히 맞물림.
- 적 은유(티켓팅 서버·매크로·암표·악플)가 팬 실경험과 1:1이라 설명 없이 바로 웃김.

**약점 (보완 후에도 남는 것)**
- 파일럿(v1) 범위 안에서는 최종 흑막이 한 번도 등장하지 않음 → W2 아웃트로의 "낯선 서명"(G8) 한 줄로만 버팀. v1.x에서 **흑막의 그림자 컷 1장**(실루엣만)을 Final 전에 배치하면 긴장감이 생김.
- "빛이 흐려지면 세계가 어떻게 되는가"가 추상적. 콘서트가 취소된다 / 응원봉이 꺼진다 같은 **구체적 손실 하나**를 W1 아웃트로에 박아두면 동기가 선명해짐.
- 13장 카드의 의미(G3)와 봉이가 내려온 이유(G4)는 떡밥 상태. v2 전에 발주자 결정 필요.
- 이스터에그·팬덤 언어 시트(T8·T12)가 비어 있어 "아는 사람만 아는" 레이어(L2·L3)는 아직 0%. 공감 유머의 절반은 여기서 나옴.

## 2. 레이아웃

- HUD: 점수(좌상)·잔기(우상)·일시정지(우상 아래)·보스 체력바(상단 98~124px) — §11 배치대로. 하단 1/3은 조작 영역으로 비워 둠.
- 대사창: 하단 212px + 초상화 110×120 좌우 → 동방식 구도. 서사 지문(화자 없음)은 기울임·하늘색으로 구분.
- 수정한 겹침: 스테이지 배너와 대사창 동시 노출(타이밍 조정), 프롤로그 "13/13" 라벨과 초상화 겹침, 토스트·"새로고침" 라벨과 보스 체력바 겹침.
- 남은 과제: 일시정지 버튼(44×32)이 엄지에 작음 → 실기기에서 48px 이상 권장. 보스 체력바 글자 15px는 소형 폰에서 작게 보일 수 있음. 초상화·컷씬은 아이콘 합성 플레이스홀더라 완성도는 도트 에셋 교체(T22) 뒤에 판단.

## 3. 입력 반응

- 드래그: 목표 지점까지 1,400px/s로 추종 → 체감 지연 1프레임 수준. 손가락 오프셋 80px.
- 버튼: pointerdown에서 즉시 축소 피드백, pointerup에서 실행. 대사 탭은 즉시 전체 출력 → 다음 줄.
- 의도된 지연: 씬 페이드 200~500ms, 프롤로그 카드 탭 대기 350ms(대사창 닫는 탭 오작동 방지).
- 주의: 이 리뷰는 브라우저 패널이 백그라운드라 프레임이 1fps로 제한돼 **물리·타이머를 코드로 고정 스텝 구동**해 검증함. 실제 터치 지연·60fps 유지 여부는 실기기에서 확인 필요.

## 4. 탄막 슈팅 장르 반영도

**반영됨**: 작은 피격 판정(반지름 6px, 흰 점으로 표시) / 자동 발사·파워 2→3열 / 잔기 3·컨티뉴 없음 / 피격 시 무적 1.5초 + 화면 탄 소거 / 보스 3페이즈(조준 부채꼴 → 새로고침 재배치 → 전방위 회전·가속) / 체력바를 대기번호로 바꾼 연출 / 숫자(999,999) 탄막 / 노미스 보너스.

**아직 약한 것 (v1.x 제안)**
1. 탄 밀도가 "탄막"보다 "캐주얼 슈팅"에 가까움 — 기획 포지셔닝(2~3분 공감 아케이드)엔 맞지만, 보스 P3는 밀도 1.5배·탄 색 2종(조준탄/고정탄) 구분 권장.
2. 페이즈 전환 시 탄 → 점수 아이템 변환(탄소거 보상)이 없음. 장르 관례이자 쾌감 포인트.
3. 그레이즈·콤보 배율이 없어 랭킹 변별력이 낮음 — 잡몹 연속 격파 배율(×1.1~×2) 추가 제안.
4. 봄(긴급 회피)이 없음 — D16 아케이드 표준에는 맞지만, 모바일 캐주얼 유저용으로 "응원봉 흔들기" 1회 봄은 검토 가치 있음.
5. 적 탄 속도 차등·예고(텔레그래프)가 없어 보스 P2 재배치 직후 즉사 느낌이 날 수 있음 — 플래시 후 0.3초 탄 정지 권장.

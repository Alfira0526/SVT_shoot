# 비주얼 방향 전환 — 도트 전제 폐기 → '사진 듀오톤 + 플랫 벡터' (2026-10-24)

발주 피드백: "배경은 저작권 없는 실제 이미지로 고도화. 대사+이미지 형태라 기존 이미지를 그대로/수정해 써도 됨. 도트 전제가 전체 퀄리티를 제한하면 방향을 버리고 새 방향을 찾아라."

## 1. 왜 도트를 버리나

| 항목 | 도트 전제 | 실제 상태 | 판단 |
| --- | --- | --- | --- |
| 캐릭터 | 도트 스프라이트 | 런타임 도형 + Twemoji 벡터 초상화 | 이미 도트가 아님 |
| 컷씬 | 도트 일러스트 | 벡터 SVG 합성 | 도트가 아님 |
| 배경 | 도트 타일 | 절차적 그라데이션·도형 | 저해상도 느낌만 남고 정보량이 없음 |
| 제작 역량 | 도트 아티스트 필요 | 아티스트 없음(AI 도트 도구는 저작권·일관성 리스크) | 병목 |

도트는 '레트로 아케이드' 분위기를 약속하지만 이 게임의 핵심은 **대사(정령의 거짓과 각성)와 장면(팬덤 경험)**이다. 도트 품질을 끌어올릴 수단이 없는데 도트처럼 보이려다 모든 레이어가 "임시 도형"에 머물렀다. → 전제 폐기.

## 2. 새 방향: 사진 듀오톤 + 플랫 벡터

**한 줄**: 실사 사진을 세계 팔레트로 눌러 '분위기 레이어'로 깔고, 그 위에 선명한 플랫 벡터(초상화·UI·탄)가 올라가는 **비주얼 노벨 × 탄막** 룩.

- **배경(사진)**: Wikimedia Commons의 CC0(Unsplash 이관분) 사진 19장. `scripts/fetch-backgrounds.mjs`로 수집(라이선스 CC0/PD/CC BY만 허용, SA·NC·ND 배제), `scripts/build-backdrops.mjs`로 480×800 세로 크롭 → 채도 35~60% → 세계색 틴트(듀오톤) → 하단 그라데이션(대사창·HUD 영역) → 비네트 → 필름 그레인. 사진마다 다른 색온도·압축 질감이 한 팔레트로 묶인다.
  - 세계 13 + 피날레: `public/assets/backdrops/<worldId>.jpg` (밝기 0.55~0.68 — 탄 가독성 우선)
  - 프롤로그 컷씬 c1~c5: 같은 파이프라인으로 밝게(0.75~1.0) 가공해 **기존 파일명 그대로 교체** → 코드 수정 없음. 벡터판은 `docs/legacy/`에 보관.
  - 얼굴이 식별되는 인물 사진은 배제(초상권·실존 인물 연상). 뒷모습·실루엣·사물·빛만.
- **인게임 사진 사용 규칙**: 사진은 depth -9.8, 그 위에 기존 절차 배경(`WorldBackdrop`)을 알파 0.42로 얹어 상징(D-1 전광판·REC 점·불씨)과 움직임만 남긴다. 별은 18개로 축소. 사진은 14초 주기로 14px 드리프트(정지 화면 느낌 제거).
- **초상화(벡터)**: Twemoji 동물 + 소품 합성 유지. 동물은 노션 T1 매핑표 13종으로 재배정(아래). 둥근 몸·파스텔 카드 프레임이 사진 위에서 '스티커'처럼 분리돼 보이는 것이 의도.
- **UI**: 플랫 패널 + 2px 팔레트 스트로크(기존). 사진 위 가독성을 위해 타이틀 하단 70%에 딥 퍼플 그라데이션 딤.
- **스프라이트(플레이어·탄·몹)**: 소형 도형 유지. 사진 위에서는 오히려 '빛의 입자'로 읽혀 세계관(빛)과 맞는다. 추후 교체 시에도 벡터 글로우 방향.

## 4. 대사 톤 리라이트 원칙 (같은 날)

피드백: "대사가 어색하고 직접 발화." → 캐릭터가 자기 **거짓/깨달음을 문장으로 선언**하던 부분을 전부 걷어냈다.

1. **선언 금지**: "나는 ~라고 믿어", "~였던 거였어"처럼 테마를 말로 요약하지 않는다. 거짓은 **습관·규칙 설명·딴청**으로, 각성은 **작은 행동 하나**(의자에 앉기, 폰 내리기, 손 떼기)로 보인다.
2. **구체물 하나**: 매 대사에 손에 잡히는 디테일(대기번호 23,041 · 7열 빈자리 · 열두 번째 시즌 · 4:45 · 자릿세 0원).
3. **마지막 줄은 농담이거나 요청**: 교훈으로 끝내지 않는다. ("너 내일도 올 거지?", "딸깍.")
4. **팬덤 리소스 구조 차용(원문·실명·가사 무참조)** — 발주자 노션의 팬 프로젝트에서 **규칙·형식**만 가져왔다:
   - 캐럿포카/캐럿빙고(포카 수 대결·중복 불인정·얼굴 나오면 인정·25칸 빙고) → **픽**: "중복은 안 쳐 줘, 얼굴 나오면 인정" / 각성 "빙고 한 줄, 중복인 나로"
   - 가사 퀴즈(눈으로 읽지 말고 귀로만·1오답 종료) → **울림**: "가사 보지 말고 귀로만. 어느 게 내 목소린지 찾아 봐"
   - 앨범 자켓 퀴즈(크롭 확대·콤보 배수·시즌 첫 챔피언 금색 박제·D-3 빨간 펄스·데일리 스트릭) → **셈이**(콤보 배수·금색 박제), **찰나**(픽셀 확대), **습작**(크롭해서 알아보기), **디원**(빨간 깜빡임), **잔불**("탈덕 예정 스트릭 천 일")
5. 루멘(가이드)은 겁 많고 말 많고 응원봉 농담을 못 참는 성격으로 고정. 설명은 첫 브리핑 4줄로 끝.
6. **v4(같은 날 추가 피드백 "뚝뚝 끊김·말투가 다 똑같음")**: 단문 나열을 연결어미로 잇고, 정령 13·나·친구·무결의 어미·속도·감탄사를 전부 분리. 정령별 보이스는 T1 번호(연령순)로 오마주 대상의 **공개된 성격·습관**만 반영 — [voice_guide.md](voice_guide.md).

데이터: `story_canon.json`(dialogue·finale) → `npm run story`(`tools/build_story.mjs`, Python 불필요) → `dialogue_worlds.json` 재생성. 루멘 대사는 `dialogue_lumen.json` 별도.

## 5. 남은 것

- 보스 스프라이트·플레이어 기체는 아직 소형 도형. 사진 배경과 어울리나, 벡터 글로우 리디자인 여지.
- 사진 교체는 `npm run bg -- --list "검색어"`로 후보 확인 → `--pick key "File:..."`로 지정 → `npm run backdrops`.

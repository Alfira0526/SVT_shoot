## 아침에 직접 보면 좋은 것 (5분)

1. 라이브 접속 → 스토리 모드 → 프롤로그(새 컷씬 6장·첫 2줄·마지막 2줄 추가) → 지도에서 루멘 브리핑 5줄.
2. 아무 세계 하나: 인트로 끝에 루멘 한 줄(힌트) → 보스 → 각성 대사 뒤 루멘 윙크 리액션.
3. 설정 → 정보·크레딧(문의 링크·출처), 설정 → 프롤로그 보기.
4. 카톡에 라이브 링크 붙여넣기 → 카드 이미지(봉이 초상화 + 제목) 확인. 안 바뀌면 카카오 공유 디버거에서 캐시 초기화.

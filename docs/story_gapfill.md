# 스토리·기획 공백 보완 노트 (v1 파일럿 구현 기준)

노션 기획서 v2.9는 결정 로그와 확정 대사는 촘촘하지만, 장면과 장면 사이의 연결 고리·동기·설정 설명이 비어 있는 곳이 많습니다. 아래는 구현하면서 메운 공백 목록입니다. **확정 대사 원문은 한 글자도 바꾸지 않았고**, 보완 대사는 각 dialogue JSON 줄에 `"gap": "G번호"` 필드로 표시해 두었습니다. 마음에 안 드는 줄은 JSON에서 지우거나 고치면 바로 반영됩니다.

톤 가이드(§2.3) 준수: 훈훈·유머 한정, 실명·그룹명 없음, 로맨스 코딩 없음, 캐릭터 성격 과잉 확정 없음(여백의 원칙).

## C. 게임 시스템 공백 → 채운 내용

| 공백 | 채운 방법 |
| --- | --- |
| 아이템 드롭 규칙 없음 | 데이터 구동: 스폰 그룹의 `drop` 필드(마지막 적이 확정 드롭) + 랜덤 드롭(응원봉 4% / 꽃씨 1.5% / 실드 4%). 잔기 상한 5 |
| 피격 후 "짧은 무적"의 수치 없음 | 1.5초 무적 + 피격 순간 화면의 적 탄 전부 소거(재개 즉사 방지, 아케이드 관행) + 파워 2열로 초기화 |

| 보스 체력바=대기열 숫자 (W2만 해당) | W2: `대기번호 999,999 → 0` / 그 외 보스: 퍼센트 |

## D. 여전히 발주자 결정이 필요한 것

3. **W2 신규 대사 승인** — intro 4줄, bossMid 2줄, outro 3줄.
4. **프롤로그 "읽쥋" 표기** — 오타 수정 유지 여부.
5. **잔기 상한 5·드롭 확률** — 밸런싱 단계(v1.x)에서 재조정.

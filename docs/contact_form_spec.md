# 문의·제보 구글폼 설계 (§14 리스크 대응 접수 창구)

드라이브 폴더 **덕질할 결심 운영** 안에 접수 시트와 이 설계서의 사본이 있습니다.

- 접수 시트: 문의·제보 접수 (덕질할 결심) — 폼 응답이 '설문지 응답' 탭에 자동 누적, 첫 탭은 처리 현황 대장
- 폼 완성 후 `src/config/constants.js`의 `CONTACT_URL`에 폼 짧은 링크를 넣고 push → 게임 설정 → 정보·크레딧에 "문의·제보: 탭해서 열기"로 노출

## 폼 구성

| # | 질문 | 형식 | 필수 |
| --- | --- | --- | --- |
| 1 | 유형 | 객관식: 버그·오류 제보 / 건의·아이디어 / 저작권·권리 관련 요청 / 랭킹 이상 신고 / 기타 | ✔ |
| 2 | 내용 | 장문 | ✔ |
| 3 | 재현 경로 | 단답 | |
| 4 | 기기·브라우저 | 단답 | |
| 5 | 게임 닉네임 | 단답 | |
| 6 | 회신 받을 이메일 | 단답(이메일 검증) | |
| 7 | 스크린샷·영상 링크 | 단답 | |

파일 업로드 질문은 응답자 로그인을 강제하므로 쓰지 않습니다.

## 설정

- 응답 → 스프레드시트 연결 → 기존 스프레드시트 선택 → "문의·제보 접수 (덕질할 결심)"
- 응답 → 새 응답에 대한 이메일 알림 받기 → 켜기 (소유자 지메일 수신)
- 설정 → 응답: 이메일 수집 안 함, 로그인 불필요, 응답 횟수 제한 없음
- 확인 메시지: "접수됐어요. 회신이 필요한 경우 남겨주신 이메일로 답장드립니다."

## 운영 규칙

- 처리 상태: 접수 → 확인 중 → 조치 완료 / 보류
- 권리 관련 요청은 접수 즉시 해당 요소 교체 또는 비공개 전환 (기획서 §14)
- 랭킹 이상 신고는 Supabase Table Editor에서 해당 행 확인 후 삭제

# 스토리라인·구성요소 점검 (2026-10-24 야간 작업)

기준: 현재 저장소의 캐논(`story_canon.json` → `worlds.json`·`guardians.json`·`dialogue_worlds.json`), 프롤로그(`dialogue_prologue.json`), 피날레(무결). 노션 v2.9 기획서는 구조 참고용.

## 1. 현재 스토리 구조 (요약)

- 프롤로그: 공연 뒤 부스에서 마지막 카드 한 장 → 럭키카드(최고 옵션) → 켠 적 없는 응원봉에 불 → "???: 드디어, 누가 날 봤네."
- 다중세계 지도: 팬덤 경험 13세계(입덕·뽑기·대기열·캡차·떼창·총공·굿즈·직캠·컴백·새벽·졸업·2차창작·버티기). 세계마다 정령 1명이 '거짓' 하나에 갇혀 있고, 보스 격파 = 거짓 끊기 = 정령 각성. 클리어 코인으로 다른 세계 해금(비연쇄).
- 피날레: 13 각성 후 '완결의 문' — 루멘의 그림자 **무결**("여한 없지? 여기서 접으면 아무도 안 아파")을 거절하고 마침표를 쉼표로 바꾼다.
- 테마: 덕질의 거짓말들(멈추면 진다·안 사면 가짜·남겨야 진짜·완결이 제일 예쁘다)을 하나씩 끊고, 끝내지 않고 이어가는 마음.

강점: 세계마다 '거짓(lie)·원함(want)·필요(need)' 3축이 정확히 설계돼 있고, 각성 대사가 전부 "거짓이 깨지는 순간"을 위트로 보여준다. 무결이 외부 악당이 아니라 루멘(=플레이어의 응원봉 빛)의 그림자라는 설계는 테마와 정확히 맞물린다.

## 4. 남은 공백 (발주자 결정·v1.2 제안)

1. **루멘 = 봉이 명칭 이원화**: 코드 id는 bongi, 표시명은 루멘, 브리핑에서 "봉이라고 불러도 돼"로 봉합. 도감·정보 화면 표기를 한쪽으로 통일할지 결정 필요.
2. **13 = 멤버 수 리스크** — 구캐논 verify에 최고위험으로 기록돼 있었음. 노션 D23은 '13 명시 허용'으로 결정했으므로 현 상태 유지(발주자 인지 사항).
3. ~~엔딩 크레딧 없음~~ → 쉼표 연출 뒤 엔딩 크레딧 롤(함께한 열넷·닉네임·출처, 탭으로 건너뜀) 추가. 완주 보상(루멘 최종 폼·타이틀 배지)은 v1.2.
4. ~~루멘 초상화 표정 1종~~ → wink(각성 리액션)·worry(피날레 직전) 2종 추가 반영.
5. **용어 통일(정령 vs 수호자)** — 캐논·대사는 '정령', UI는 '수호자 도감'·타이틀 "13인의 수호자". 한쪽으로 통일 권장(대사 톤상 '정령'이 자연스러움). 코드 위치: `TitleScene`, `GuardianScene` 헤더, `MultiverseScene` 토스트.
6. **랭킹 제출 시점** — 현재는 게임오버 때만 점수를 제출하고, 세계 클리어는 지도로 바로 복귀해 제출이 없음. 클리어 점수도 올릴지(세계별 13회 제출 허용 여부), 아니면 엔들리스 거리만 랭킹으로 쓸지 결정 필요. 코드 위치: `GameScene._clearWorld` / `_toRanking`.

## 6. 검증 방법

브라우저 패널이 백그라운드에서 0fps로 묶이는 환경이라, Phaser 루프를 멈추고 `game.step()`을 고정 스텝으로 호출하는 자동 플레이 하네스(대사 자동 넘김·보스 조준·개발자 모드 무적)로 세계를 완주시켜 대사 시퀀스와 상태 전이를 확인했다. 실기기 체감(터치·프레임)은 별도 확인 필요.
